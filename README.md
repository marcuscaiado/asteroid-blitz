## ✨ Features & Highlights

- 🚀 **Zero-Gravity Inertia Physics**: Realistic ship thrust, momentum drift, and screen wraparound mechanics.
- 🪨 **Splitting Asteroid Formations**: Large rocks fragment into fast-moving medium and small debris chunks.
- 🛸 **Hostile Alien UFOs**: Random saucer encounters firing targeted laser pulses.
- ⚡ **Emergency Hyperspace Warp**: Teleport out of danger in critical moments (with risk of blind-drop collision!).
- 🔊 **Authentic Arcade SFX**: Classic vector heartbeat bass, thruster roar, and crisp wireframe explosions.

## 🕹️ Controls

| Action | Desktop / Keyboard | Mobile / Touch |
| :--- | :--- | :--- |
| **Rotate Ship** | `A / D` or `Left / Right` | Touch Left / Right turn buttons |
| **Thrust Engine** | `W` or `Up Arrow` | Hold **THRUST** Button |
| **Fire Blaster** | `[SPACEBAR]` | Tap **FIRE** Button |
| **Hyperspace Warp** | `[SHIFT]` or `[H]` | Tap **HYPERSPACE** Icon |
